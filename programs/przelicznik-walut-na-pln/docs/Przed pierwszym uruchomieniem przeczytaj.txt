PRZELICZNIK WALUT NA PLN 4.6.0

Wersja portable:

1. Pobierz plik „Przelicznik-walut-na-PLN.exe” z sekcji GitHub Releases.
2. Uruchom pobrany plik. Program nie wymaga instalacji.
3. Jeżeli przy pierwszym uruchomieniu pojawi się Microsoft Defender SmartScreen,
   wybierz „Więcej informacji”, a następnie „Uruchom mimo to”.

Połączenie z internetem jest potrzebne do pobierania kursów NBP.

Uruchomienie kodu źródłowego:

1. Zainstaluj Python.
2. W katalogu programu wykonaj:

   python -m pip install -r requirements.txt
   python src/przelicznik_walut_na_pln.pyw

Program obsługuje EUR, USD, GBP, CHF, CNY i CZK.
