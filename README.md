# Petit Portable Software

Kolekcja niewielkich, przenośnych programów i praktycznych narzędzi dla systemu Windows.

## Zasady udostępniania

Oprogramowanie publikowane w tym repozytorium jest udostępniane:

- bezpłatnie,
- bez limitu czasu,
- bez obowiązkowych opłat abonamentowych.

Szczegółowe informacje dotyczące konkretnego programu, jego wersji i wymagań będą znajdować się w jego katalogu oraz w sekcji GitHub Releases.

## Struktura repozytorium

Każdy program będzie przechowywany w osobnym katalogu wraz z dokumentacją i plikami potrzebnymi do jego zbudowania. Gotowe, podpisane pliki wykonywalne oraz sumy kontrolne będą publikowane w GitHub Releases.

## Wsparcie projektów

Jeżeli doceniasz moją pracę, możesz dobrowolnie wesprzeć rozwój projektów, [stawiając kawę](https://buycoffee.to/beniamin-tv6).

W każdym programie w lewym dolnym rogu znajduje się przycisk **Wsparcie**, który otwiera stronę umożliwiającą przekazanie wsparcia.

Wsparcie jest całkowicie dobrowolne i nie wpływa na dostępność ani czas działania oprogramowania.
